# GRC103-Week-1-Lab-Submission
Objective
This lab involved performing a vulnerability assessment against a Metasploitable 2 virtual machine using Nmap, Nikto, and Nuclei. The objective was to identify security weaknesses and assess the associated risks from a Governance, Risk, and Compliance (GRC) perspective.

Tools Used
Nmap
Nikto
Nuclei
Kali Linux
Metasploitable 2

Repository Contents
Final Lab Report
Risk Assessment Table
Executive Summary
Vulnerability Assessment Findings
Supporting Evidence and Screenshots

Key Findings
Weak FTP credentials
Anonymous FTP access
Outdated Apache version
Outdated PHP version
Missing HTTP security headers
Weak SSH configurations
Critical FTP vulnerability (CVE-2011-2523)

Conclusion
The assessment identified several vulnerabilities and security weaknesses that could increase the risk of unauthorized access and system compromise. Recommendations were provided to improve the overall security posture of the system.
